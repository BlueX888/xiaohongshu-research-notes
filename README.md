# xiaohongshu-research-notes

这是一个面向计算机科研的本地资料库。资料库收录「小小研究僧」的 259 篇小红书图文帖子。帖子以深度学习和计算机视觉为主。

本科生和研究生可以按科研任务查阅帖子。

## 科研用途

- **选题与读论文**时，按数据和算力需求评估课题。按研究问题梳理论文，为选择基准模型做准备。
- **设计和复现实验**时，查阅对比实验和消融实验的设计方法。核对数据处理、超参数和评测方法。
- **写论文**时，参考摘要、引言和方法部分的组织方式。检查实验结果是否支撑论文贡献。
- **回复审稿**时，按审稿意见梳理待补的说明和实验。在回复中写明稿件的修改位置。

## 本地查阅

资料库用 Markdown 文件按篇保存帖子文字。`索引.md` 按发布时间列出帖子。每篇帖子保留原帖链接。读者可以在原帖查看配图。

`查帖.py` 按关键词搜索标题、话题和正文。搜索结果附本地路径、行号和原帖链接。读者和智能体（Agent）可以据此核对帖子内容。
