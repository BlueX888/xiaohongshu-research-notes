本库面向从事计算机科研的本科生和研究生。 [浏览帖子目录](索引.md)

## 查帖与引用

查帖需要 Python 3.8 或更高版本。

如果给基准模型（baseline）添加模块后指标未提升，按以下步骤查帖。

1. 切换到项目目录。
2. 运行查帖命令。

   ```bash
   python3 查帖.py 'baseline' '模块' --limit 3
   ```

   查帖脚本最多显示 3 篇帖子。
3. 打开结果指向的 Markdown 文件。
4. 记录帖子标题、本地路径、行号和原帖链接。

如果帖子带有 `仅图片` 标记，打开原帖查看图片。

智能体（Agent）使用相同的查帖流程。排查实验时，向智能体提供实验配置。智能体根据帖子正文与实验配置列出排查步骤。 [智能体查帖说明](AGENTS.md)

将帖子建议用于论文或实验前，对照原论文、代码或实验记录核实建议。
