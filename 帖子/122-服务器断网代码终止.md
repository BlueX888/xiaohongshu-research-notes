不知道大家有没有经历这种心碎时刻，辛辛苦苦在远程服务器上跑着一个复杂的深度学习模型，可能已经跑了几天几夜，眼看就要出结果了！突然，本地的网络出了问题，或者只是合上了笔记本电脑，再打开时SSH连接直接显示Connection closed by remote host！那一刻，感觉整个世界都崩塌了！跑了一半的代码，所有进程全部终止，之前的心血全部白费！特别是对于跑大模型、做数据预处理、或者进行任何需要长时间运行的科研任务来说，这种掉线简直是噩梦！
今天给大家安利一个防掉线神器tmux。首先是安装命令：sudo apt install tmux
然后给出常用的指令：
1. 创建会话：tmux new -t my_exp。启动一个名为my_exp的新会话。所有重要代码都从这里开始运行！
2. 查看会话列表：tmux ls。
3. 即使网络中断，等恢复之后可以连接会话：tmux attach -t my_exp
4. 彻底结束会话：tmux kill-session -t my_exp
只要你是在tmux会话里运行的代码，即使你直接关闭了SSH窗口，代码都不会停！
