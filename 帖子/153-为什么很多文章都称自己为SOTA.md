# 为什么很多文章都称自己为SOTA

SOTA，是 state-of-the-art 的缩写，有的文章将其视为性能上的 Number one。 而有的文章将其视为性能上，或者是影响力上的拔尖者。因此，就存在这样的描述，比如 the state-of-the-art method RANSAC，这个方法是很早的经典的方法。对于那些认为性能上的 Number One，其实绝大部分的文章只是在自己所选择的对比方法中，自己的方法是 Number One 而已，并非领域内所有文章中的 Number One。另外，在一些交叉领域，方法本来就少，你选择了一些新的模型进行的改进，很容易超过旧的模型的结果，这个时候在这个交叉领域，自然也能算性能上的 SOTA 了。
