最近频繁被问到的一个问题就是，为什么按照readme 一步步操作去配置环境，结果却总是接二连三的报错。这个问题在刚搞深度学习的本科生和交叉学科的研究生中尤为常见。结果却是因为他们都在自己的笔记本上运行代码。自己的笔记本有的根本没有 专门的 GPU，而流行的深度学习代码大都基于 Pytorch 框架进行的，需要用到 GPU 加速。所以即使按照原本的 readme 进行配置，也是一开始就失败了。所以要想把代码跑起来，尽量去依托实验室提供的高性能计算服务器，实在不行就自己去网上租，不然直接在第一步就被 pass 了[笑哭R][笑哭R][笑哭R]
