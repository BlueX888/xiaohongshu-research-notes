1. Training-Free 方法，不需要训练，单卡甚至 CPU 就能跑，复现只需推理代码。这是对算力门槛要求低、同时A会认可度高的方向之一。Upsample Anything (CVPR26) 利用输入图像的边缘和结构信息做特征上采样，完全无需训练。单张224×224大小的图像只需0.4秒，GPU内存降低16倍。PaPr (ECCV24) 用轻量ConvNet单步识别冗余patch并剪枝，无需重训练，大约百分之70的冗余patch被去除，FLops降低3.7倍。EMLoC (ECCV24) 提出了Training-free多模态长上下文学习，chunk压缩和自适应剪枝，实现了4.4 倍上下文压缩的同时，无性能损失，即插即用。

2. 参数高效微调 (PEFT) 或小样本 CLIP 适配，只需训练少量参数，训练时间以小时计。TOGA (CVPR26) 训练时用异构图文图教师蒸馏到轻量cache adapter，测试期完全去掉教师。Task-Aware Prompt Gradient Projection (ICCV25) 联邦增量学习，仅用baseline 1%的训练参数，性能提升5%。TR-PTS (ICCV25) 任务相关参数与Token选择，超越全量微调3.4-10.35%。

3. Token压缩 、剪枝 、合并，不需要改模型结构，操作在输入/特征层面，计算图不变，复现简单。TCA: Token Condensation as Training-free TTA (ICCV25) 基于CLIP的token剪枝做在线测试时适应，无需重训练。

4. 数据高效训练。Diffusion Dataset Condensation (CVPR26) 仅用原始0.8%的图像训练扩散模型, 训练加速233倍。Data-Efficient Video Pre-training (CVPR26) 冻结图像基础模型，只训练时序推理模块。

5. 轻量级架构设计。ViT³ (CVPR26) 线性复杂度ViT，将attention重写为test-time training。ConvNeur (CVPR26) 全局-局部解耦的双分支架构，次二次方缩放。
